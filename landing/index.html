OVERVIEW & PROBLEM STATEMENT

A centralized decision-support platform for AICTE Bureaus/Cells

AICTE receives institution-related complaints through disparate channels — including the Regulation Bureau (RB), Public Grievance Redressal Cell (PGRC), and other specialized cells. VIGIL unites these records into a single institutional intelligence layer to eliminate duplicate investigations, detect cross-bureau overlaps in real time, and assist authorized AICTE officials with evidence-backed coordination.

1. Institution DNA Engine (Core Innovation)

VIGIL's flagship innovation resolves inconsistent institution names, abbreviations, and missing AICTE Permanent IDs across independent bureau complaints using a 4-stage hybrid matching pipeline.

  • Stage 1: Exact AICTE Permanent Institution ID matching
  • Stage 2: RapidFuzz token scoring + Double Metaphone phonetic layer
  • Stage 3: 384-dim Sentence-Transformers + pgvector cosine similarity
  • Stage 4: Groq Llama LLM Judge for ambiguous candidate arbitration

2. Cross-Bureau Overlap Intelligence

Identifies multiple concurrent complaint investigations concerning the same institution across RB, PGRC, and other cells, auto-proposing shared War Room workspaces to prevent conflicting or duplicated effort.

  • Dynamic temporal property graph with timestamped action edges
  • Automatic 30-day cross-bureau overlap detection heuristics
  • Shared War Room workspace with recommended lead bureau
  • Real-time Socket.io coordination notifications to nodal officers

3. Institution Risk DNA Engine

Computes an advisory institutional risk score (0–100) combining complaint frequency, severity, sentiment trends, cross-bureau overlap density, and resolution delays to flag emerging hotspots.

  • Advisory indicators: GREEN (<40), YELLOW (40–75), RED (>75)
  • Time-series trend projection with 95% CI bands (Prophet-compatible interface)
  • Auto-drafted Preemptive Intervention Briefings for RED institutions
  • Advisory decision-support — does not imply confirmed violations

4. AI Complaint Co-Pilot

A natural-language conversational assistant empowering AICTE officers to query multi-bureau complaint records, track ageing trends, synthesize summaries, and draft coordination memos.

  • Natural query parsing: "Show institutions with complaints across multiple bureaus"
  • Grounded RAG retrieval over canonical institution metadata
  • Drafts official coordination memos for human officer sign-off
  • Role-based query filtering ensuring bureau-level authorization

SYSTEM ARCHITECTURE

Three Coordinated Processing Layers

VIGIL structures its intelligence into three decoupled processing layers, coordinated via LangGraph and Postgres pgvector with strict role-based access control.

LAYER 1 • IDENTITY RESOLUTION

VIGIL DNA Core

Institution identity canonicalization through a 4-stage hybrid matching pipeline.

COGNITIVE RESOLUTION PIPELINE Exact → Fuzzy → Vector → LLM Judge
  • AICTE Permanent ID exact index lookup
  • RapidFuzz token scoring & Double Metaphone phonetic matching
  • 384-dim Sentence-Transformers + pgvector cosine similarity
  • Groq Llama LLM Judge for ambiguous candidate arbitration
  • Mandatory human-review routing for confidence < 0.85
LAYER 2 • MULTI-BUREAU COORDINATION

VIGIL Coordinate

Cross-bureau overlap intelligence, temporal complaint graph, and War Rooms.

GRAPH REASONING ENGINE Multi-Bureau Temporal Traversal
  • Temporal property graph linking institutions, complaints & bureau actions
  • 30-day temporal overlap detection heuristics (RB ↔ PGRC)
  • Automated War Room workspace recommendations
  • Multi-bureau SLA monitoring and deadline escalation alerts
  • Systemic root-cause clustering and repeated grievance detection
LAYER 3 • PREDICTIVE ANALYTICS

VIGIL Intelligence

Institutional Risk DNA, predictive analytics, and AI Complaint Co-Pilot.
